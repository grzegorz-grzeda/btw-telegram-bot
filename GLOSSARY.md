# btw

A personal "by the way..." to-do list kept through Telegram chat. Things you remember in passing get jotted down so you can deal with them later.

## Language

**List**:
The single collection of open items belonging to one chat. There is one per chat, not one per type.
_Avoid_: Lists, todo list (when meaning a single type's items)

**Item**:
One thing to remember, written as a short line of text. It has exactly one type, or is unsorted.
_Avoid_: Task, entry, todo

**Type**:
The kind of an item: food, stuff or do. The set is fixed.
_Avoid_: Category, tag, label, list

**Food**:
A type: groceries to buy.
_Avoid_: Groceries, shopping

**Stuff**:
A type: non-food things to buy.
_Avoid_: Things, shopping, purchases

**Do**:
A type: something to do that isn't buying.
_Avoid_: Task, todo, chore

**Unsorted**:
The state of an item that hasn't been given a type yet. It is not a fourth type.
_Avoid_: Uncategorized, other, misc

**Done**:
An item that has been ticked off. It no longer appears in the list.
_Avoid_: Completed, deleted, removed
